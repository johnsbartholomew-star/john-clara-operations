# How to use this hub

## In Codex

- Open the local folder `/Users/magnusshouse/Documents/Codex/john-clara-operations` as a project.
- Ask Codex to use `$home-base-operator` for cross-project coordination.
- For focused work, point the task to the matching file under `workstreams/`.

## In ChatGPT

- Connect the GitHub plugin when it is available to the account.
- Reference the private repository `johnsbartholomew-star/john-clara-operations` in the prompt.
- Keep approvals and active conversation in Home Base; save only durable, non-sensitive changes here.

## Updating the hub

Before changing durable context:

1. Verify whether the fact is confirmed or time-sensitive.
2. Update the relevant status file.
3. Add a short entry to `DECISIONS.md` when a real decision changed.
4. Review the diff for sensitive information before committing and pushing.

Do not copy entire conversations into this repository. Distill confirmed decisions, constraints, artifacts, and unfinished next steps.
