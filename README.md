# John & Clara Operations

Private operating repository for reusable context, workflows, drafts, and decision records shared across John's ChatGPT and Codex work.

## Start here

1. Read `AGENTS.md` for working rules.
2. Read `CONTEXT.md` for durable, non-sensitive context.
3. Open `PRIORITIES.md` for the current focus and next actions.
4. Use `workstreams/` for project-specific status and artifacts.

## Purpose

- Reduce repeated explanations across tasks.
- Keep decisions and next actions in one version-controlled place.
- Reuse approved workflows and templates without copying long prompts.
- Preserve clear boundaries around external actions and sensitive data.

## Safety

Never store passwords, access tokens, account numbers, private health records, tax identifiers, or browser-session data here. Treat financial figures, job listings, benefit rules, vehicle listings, and account status as time-sensitive and verify them before acting.
